Cybersecurity spotlight

Pentesting the next attack surface: AI agents.

VAPT-certified (GuideM, 2023), with hands-on assessments across several client systems. The project I'm most proud of is a set of tools for something very few people test yet: attacking AI agents, where the weak point is the prompt rather than a normal HTTP endpoint.

  • OWASP LLM Top 10 aligned. A full engagement framework built around the current standard for AI application risk.
  • ~70 test techniques across prompt injection, jailbreak, data leakage, tool abuse, memory poisoning, privilege escalation, and denial-of-wallet.
  • CVSS baseline anchors for consistent scoring, and a four-tier confidence verification model to eliminate false positives.
  • A strict evidence format on every finding: the exact attack prompt, a control prompt, and an analysis of how the two diverged.
